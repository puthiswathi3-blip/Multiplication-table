#### **Multiplication Table Generator**



##### **About the Project**



This project is a simple Python program that generates a multiplication table for a number entered by the user. The user can also specify the limit up to which the table should be displayed.



##### **Features**



* Accepts a number from the user.
* Allows the user to enter the table limit.
* Uses a "for" loop to generate the table.
* Displays the output in a clear format.
* Simple and beginner-friendly program.



##### **Technologies Used**



* Language: Python
* Concepts: Input/Output, Variables, "for" loop, "range()", Arithmetic Operators, Formatted Strings



##### **How It Works**



1\. The program asks the user to enter a number.

2\. It asks for the limit of the multiplication table.

3\. A "for" loop runs from 1 to the given limit.

4\. The number is multiplied by each value.

5\. The results are displayed as a multiplication table.



##### **Example**



Enter a number: 7

Enter the limit: 5



Multiplication Table

\--------------------

7 x 1 = 7

7 x 2 = 14

7 x 3 = 21

7 x 4 = 28

7 x 5 = 35
